# James Harvey Drawing Portfolio

## Included
- Responsive one-page portfolio
- Home, About, Skills, Experience, Education, Gallery, CV, Contact
- Artwork search and category filtering
- Dark/light mode saved with localStorage
- Mobile hamburger navigation
- SEO metadata, robots.txt, sitemap.xml
- Accessible labels and semantic sections

## Replace before deployment
1. Add your real profile photo in place of the "JH" hero placeholder.
2. Add real artwork images. The project data is inside `script.js`.
3. Add `assets/James-Harvey-CV.pdf`.
4. Replace the sample email and social links in `index.html`.
5. Connect the contact form to Formspree, Netlify Forms, EmailJS, or your own backend.
6. Replace `https://your-domain.example/` in `sitemap.xml` and the canonical URL with your real public URL.

## Hosting
The site is static and can be deployed to GitHub Pages, Netlify, Vercel, or another static host.
